About these reports

  • The data is synthetic. The account number 111122223333 is AWS's documentation example, and no real infrastructure is shown.
  • Each report is the same single HTML file you get from the CLI. It makes no network requests, even here.
  • The demo uses tfviz's own symbols. With --icons, your reports can use the official AWS icons instead.
