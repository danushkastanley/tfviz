Summary

tfviz helps engineers review infrastructure changes before they apply them. A Terraform plan is usually hundreds of lines of changed attributes. tfviz reads the plan's JSON and draws what is actually changing: each resource in its account, region, VPC and subnet, marked as added, modified, replaced, destroyed or read during apply, with lines for the relationships Terraform recorded.

The result is a single HTML file that opens from disk in any modern browser, makes no network requests, and leaves secrets out by design. Teams attach it to pull requests or keep it as a CI artefact.

Main capabilities

  • Plan reviews. Architecture and module views, with Changes, Before and After modes.
  • State reports. From a local state file, a raw .tfstate, or directly from S3 with the user's own AWS credentials.
  • Relationship tracing. Select a resource to see what it touches, with the evidence for each link.
  • Private local explorer. tfviz explore serves the same interface to the user only, on their own machine.
  • Safe sharing. --safe-share replaces names, IDs, ARNs, account numbers and addresses with consistent stand-ins.
  • Official AWS icons. Shown from the icon pack the user downloads from AWS. tfviz doesn't bundle them.
  • CI pipelines. Documented for GitHub Actions, GitLab CI, Jenkins and Buildkite.

Who it's for

  • Platform, DevOps and cloud engineers who review Terraform or OpenTofu changes
  • Teams that review infrastructure in pull requests and want a visual summary next to the plan
  • Reviewers who need to understand a change without reading every attribute
  • Security-conscious organisations that can't send plans or state to a hosted service

When teams typically use it

  • Before approving a pull request that changes infrastructure
  • When a plan replaces or destroys resources and the impact needs to be clear
  • To document what a stack looks like from its recorded state
  • To share an architecture outside the team without exposing identifying details

Privacy and security

  • No telemetry, no accounts and no hosted service. Reports make no network requests.
  • Only approved fields reach a report. Passwords, user data, environment variables, tags and policies are withheld.
  • A changed secret shows as "Sensitive value changed", never the value.
  • Releases include checksums, SBOMs and build provenance that can be verified with gh attestation verify.

See Security and privacy for the full controls and their limits.

What tfviz doesn't do

  • It doesn't query live infrastructure. Plans are proposals and state is a recorded snapshot.
  • It doesn't run, apply or change Terraform. It only reads the JSON the user gives it.
  • It doesn't show live traffic. Lines are recorded associations.
  • It doesn't yet cover Azure or Google Cloud in detail, or run on Windows.

Tested compatibility

  • Terraform 1.16 and OpenTofu 1.13 (plan JSON format 1.2, state JSON format 1.0)
  • The hashicorp/aws provider 6.67
  • Chromium, Firefox and WebKit, opened from file:// with no network
